# Human--Abuse--Detection-in-Social-Media-Texts
This research project is focoused implicit human  abuse in social media texts using Natural Language Processing and Machine Learning techniques.
Developed a machine learning solution to detect implicit toxicity in Sinhala social-media text. Delivered STOLA, a dataset of 10,000 annotated real-world comments, and a responsive web application (HUGHUB) for live toxicity detection.
